Tipro 8×4 — 32-Key POS Keypad Conversion

Status: Completed 8×4 Ortho (32 Keys) WeAct STM32G431 CoreBoard QMK

Introduction

A 32-key Tipro 8×4 mechanical keypad module converted to QMK using a direct-wired WeAct STM32G431 controller board.

Internal Wiring & MCU

  • Microcontroller: WeAct STM32G431 CoreBoard (AliExpress reference)

Firmware

Prebuilt firmware can be downloaded from GitHub Actions (qmk_firmware) — navigate to the build firmware for mlego workflow, select the latest successful run, and download tipro32_default from the artifacts list.

Original Condition

Quick Specs

  • Layout: 8×4 POS
  • Keys: 32
  • MCU: WeAct STM32G431
  • Firmware: QMK

32-key Tipro POS macropad module powered by a high-performance STM32G431 microcontroller.
